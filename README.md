Currículo de Rickson Viana.

O projeto foi feito com HTML, CSS, e JS, não achei funcionalidades para o php no site, mas
de acordo com minhas pesquisas o github pages não roda php.

Primeiro peguei os códigos dos exemplos como referência e fui mudando as informações, adicionando e removendo
alguns dados, depois fui para a parte de estilização, aonde mudei algumas cores e animações (como os links aumentando e brilhando ao passar o cursor,
ondas na porcentagem e foto de perfil aumentando ao passar o cursor). Na parte do JS implementei a funcionalidade de tema claro e escuro e o tempo em
segundos que a pessoa passa no site.

link do currículo: https://ricksonviana.github.io/Curriculo/
