#  Currículo Online Interativo

##  Sobre o Projeto

Este projeto consiste em um currículo online desenvolvido com o objetivo de mostrar o que eu aprende nas aulas de desenvolvimento web.

O projeto foi criado utilizando tecnologias de desenvolvimento web, contendo funcionalidades que melhoram a experiência do usuário, como alternância entre modo claro e escuro, impressão do currículo em PDF, animações visuais e um formulário de contato.

---

## Tecnologias Utilizadas

- **HTML** – Estruturação do conteúdo da página.
- **CSS** – Estilização, responsividade, animações e modo escuro.
- **JavaScript** – Interatividade da página, como controle do tema, contador de tempo no site e comunicação com o formulário.
- **PHP** – Processamento dos dados enviados pelo formulário de contato.


---

##  Estrutura do Projeto

```bas
Curriculo/
```

##  Funcionalidades Implementadas

###  Interface e Design

- Layout moderno em formato de currículo digital.
- Animações de transição e efeitos visuais.
- Efeitos ao passar o mouse em elementos interativos.
- Foto de perfil personalizada.

###  Controle de Tema

- Alternância entre modo claro e modo escuro.
- Alteração dinâmica das cores da interface utilizando JavaScript.

###  Impressão do Currículo

- Botão dedicado para impressão.
- Estilos específicos para impressão utilizando `@media print`.
- Compatibilidade com exportação em PDF pelo navegador.

###  Formulário de Contato

- Campo para envio de nome, e-mail e mensagem.
- Envio dos dados sem necessidade de recarregar a página.
- Processamento das informações utilizando PHP.
- Armazenamento das mensagens recebidas em um arquivo `.txt`.

###  Recursos Interativos

- Contador de tempo de permanência do visitante no site.
- Feedback visual de ações realizadas pelo usuário.
- Animações em botões e elementos do currículo.
